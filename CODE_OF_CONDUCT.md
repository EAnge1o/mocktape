# Code of Conduct

## Our pledge

We want contributing to mocktape to be a harassment-free experience for
everyone, regardless of background, identity, or level of experience.

## Expected behavior

- Be kind and constructive in code review and issues.
- Assume good intent; optimize for clarity.
- Critique code, not people.

## Enforcement

Maintainers may remove comments, issues, or PRs that violate this policy and
may ban repeat offenders. Reports can be made via GitHub Security Advisories
or by contacting a maintainer directly.

Instances of abusive behavior are taken seriously and reviewed promptly.
